面向阿拉伯语母语者的汉语词典

核心是一套可以持续生长、可以审定、可以进入课堂的中阿词汇数据

可在手机上直接打开的样品：eesa2022.github.io/zh-ar-jis（阿拉伯语界面，从右向左）。本说明中的截图均来自这个样品。

摘要

  1. 市场上已经有中阿词典 App，如智慧宫 WPT 和麦阿尼中阿词典。它们收词多，并且带翻译功能。我们不在收词数量上和它们竞争。
  2. 我们做的是数据的组织方式。每个中文义项对应几个阿语译法，并分别标出语域、介词搭配和词根。每一条都带来源和审定状态，可以单独更新。条与条之间可以互相跳转：字带出词族，词带出搭配，搭配带出辨析，阿语词根也能反查回中文。这三件事决定了一部词典能否被译者信任、被教师用于教学。
  3. 查询要从阿语母语者的实际起点出发。样品已经支持八种键入方式，另有手写、拍照和点词续查，用户不需要先切换语言或模式。
  4. 以后可以往上叠加内容。新的专业领域、教学层、课程词表、阅读器和复习功能，都挂在同一套词条上，不必另起炉灶。
  5. 希望学院参与的是教学层和审定，不是事后作序。第一步很小：一次演示、两位教师评审、一个小班试用两周。

沙特、阿联酋等国已经把中文纳入国民教育，来华的阿拉伯留学生、译者和外交、商务人员也在增加。他们查中文时遇到的困难，和英语母语者不完全一样：

三核心价值：数据本身

界面一年内就能被别人仿出来，成体系、经过审定的数据仿不出来。下面分四个方面说明：丰富、实时、词与词的拓展性，以及可信。

3.1 丰富：一个词条有多层信息

常见的对译词典，一个词往往只给一行译文。我们的数据结构把一个词拆成十几个可以单独使用的层次，每一层都服务一个具体的使用场景。

常见的对译
安全
أمن؛ سلامة

用户无从判断「粮食安全」该用哪个，也不知道「安全带」「安理会」和它有关。

读音ānquán，声调用颜色区分；发音；逐字笔顺
义项 ①形容词「没有危险」：آمِن 和 سالِم，各注词根，并说明「平安到达」用后者
义项 ②名词「安全状态」：أَمْن 用于国家和网络安全，سَلامَة 用于生产和食品安全，أَمان 用于「安全感」
搭配国家安全、粮食安全、食品安全、网络安全……每条都能单独检索
例句按义项分开，标出「正式 / 外交 / 口语」，每个词都可以点开
词族安全带、安全帽、安全感、安全阀、安全系数、安全理事会
翻译陷阱粮食安全 = الأمن الغذائي（有没有粮食）；食品安全 = سلامة الأغذية（干不干净）
专业包追加外交包追加义项 ③「共同、综合、合作、可持续的安全观」，附官方阿语表述
语法（其他词）量词「一项安排」；离合词「安了家」；介词搭配，如「暗示」对应 ألمح إلى
文化（其他词）「安拉」与「真主」在中国穆斯林中的用法差别
来源 · 审定每个义项、每条例句都记录来源和审定人，未审定的内容会被标出

3.2 实时：按词条更新，不等再版

纸质词典的内容停在出版那一年。修订版出版至今已经十二年，「大模型」「光伏」「一带一路」的官方阿语译法都不在书里。我们的数据以词条为单位独立更新，并分三种节奏：

新词与译法新闻、外交文件、行业术语表、教师反馈
→
起草AI 生成例句和候选译法，标为「未审」
→
审定教师和译者逐条核对，并留下审定人姓名
→
发布只发布已审定的内容；用户端增量更新
→
回流用户纠错和查询记录返回，进入下一轮修订
按天单条修订改一个译法，补一条例句。已审定的旁边内容不受影响。
按月专业包外交、人工智能、伊斯兰金融、能源各自成包，可以单独开关和更新。
按年主词库版本常用词整体复核，配合学年和教材更新。

这里说的「实时」，指的是词库一直在维护：课堂上刚确定的译法，下一次推送后学生就能查到。追加内容只增加、不覆盖。例如外交包给「安全」新增一个义项，原有的两个义项和审定记录保持不变。

3.3 词与词的拓展性：一个词连着一张网

学生查完一个词，应该能顺着关系继续查下一个，而不是查完就结束。译者真正翻译的单位往往不是单词，而是搭配。我们把纸质词典里只能看、不能点的「◊ 词族」「参见」，以及隐含的搭配和对译关系，都变成可以点击和检索的连接。

字与词 词族（原书 ◊ 后的派生词，已升为独立词条） 搭配（可单独检索） 辨析 / 翻译陷阱 专业包追加 阿语译法与词根

同一张网也可以从阿语进入。在样品里输入 أمن，一次会找到九条结果：主词「安全」、外交包里的「安理会」、派生词「安全理事会」，以及「国家安全」「粮食安全」「网络安全」「全球安全倡议」等搭配。阿语母语者心里先有阿语概念，再去找中文说法，这条反向路径对他们尤其重要。

关系样品中的例子对学生和译者的用处

词族安全 → 安全带、安全阀、安全系数原书 ◊ 后的派生词升为独立词条，可以直接搜到

3.4 可信：每一条都能追溯

数据能否被教师和译者采用，取决于是否可信。我们为每个义项、每个译法、每条例句记录来源（原书参照、公开词表、AI 起草、编辑撰写、用户反馈）和审定状态。正式版只发布审定通过的内容；样品中的 AI 内容都标为「未审」。

版权方面：纸质词典只用作选词和查漏的参照，不复制其中的阿语释义和例句。例句全部重新生成，再经人工审定。我们同时准备与出版方洽谈授权。1989 年商务版和 2014 年北大社修订版都可以作为洽谈对象。

这里正是学院的位置。数据的价值最终来自谁审定过它。一条经过对外汉语教师审定的译法、辨析或例句，比一百条未经审定的内容更有用。

样品中的手写和拍照用的是免费开源组件，准确率只够演示。正式版计划改用手机端离线识别引擎，例如 Google ML Kit 的手写与文字识别，免费、离线可用；同时加入从任意 App 选中文字查词的入口。查询方式本身不变。

对学院来说，可以得到一个能直接用于阿拉伯学生教学的工具，一份关于阿拉伯学习者难点的研究数据，学生参与审定的翻译实践机会，以及可以申报的合作课题。第一步只需要投入很少的时间：

  1. 一小时演示。请院长和老师在手机上试：安全、abbd、س ل م、أمن，再点开「安全带」和底部的「النطق」（发音指南）。
  2. 两位教师评审三块数据。拼音误读说明、量词和离合词、翻译陷阱，判断它们是否值得进入课堂。
  3. 一个阿拉伯学生小班试用两周。只观察三点：从汉字、拼音、阿语三种起点能不能查到；会不会顺着词族和搭配继续查；陷阱提示是否有用。
  4. 如果试用效果成立，学院选定一个年级或一门课，作为第一批教学层词汇；我们负责把它接入词典，并署学院和教师的名字。

这一步不涉及投资，也不涉及独家条款。
